# #87 r1: series inverse, log and exp on backend/series

2026-10-12, claude. Series on the backend's kernel (`backend/series/notes.md`,
`backend/series/notes/87-r1.md`).
`detail::series::{inverse, log, exp}` keep their signatures and the recurrence path for at
most 16 terms; the Newton path is `fps::series::{inverse, log, exp}(f, out)`, in the backend's
per-thread memory (the scratch argument now feeds the recurrences only). n past 2^25 now
throws `std::length_error` before out is written. The overlap rules of the raw functions stay
(the backend allows any overlap for log and exp). `bench_series.cpp`: `<op>@kernel/<lg>`

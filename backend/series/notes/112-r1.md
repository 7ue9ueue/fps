## Changes, each measured (fps / lc-opt at 2^21 unless noted)

1. Steps on the fused ops (copies, zeros and negations gone; products in one pass; half-zero
   sources; half outputs): with the tile-hook products, inverse 1.074, log 1.141, exp 1.147.
2. Generated asm bottoms for cyclic and inverse products (ntt round, attempt 4): inverse 0.976,
   log 1.097, exp 1.102.
3. Divisions by index: lc-opt's batch inversion (`divide_by_index`) instead of a table of 1 / i
   per call from the factorials: log 1.073, exp 1.079 (and Zen 5's log/11, exp/11 1.11, 1.14 of
   main: the batch's lane totals cost ~0.8 us a call, at 4-5 calls per op; divisors below 2^13
   now from a table built once: 0.86, 0.93).
4. exp's last step at length m in two blocks (lc-opt's exp_last_step, block 3 new): exp 1.079 ->
   1.018 (2^14: 1.033 -> 0.961).
5. Sums of 2 and 3 leaf products as asm bottoms (log's residuals): log 1.073 -> 1.064.
6. log reads f' from f block by block (a copy of f only if out overlaps it), not from a d array
   of n words: log 2^18 1.043 -> 1.030, 2^21 unchanged within noise.
